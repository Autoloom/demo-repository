# Code standards

Clean rebuild of `demo-repository`, done step by step. Keep code industry-standard,
organised, clean, reusable, readable — refactor as you touch things, don't just append.

- Small, focused, named components/functions over large inline blocks.
- No dead code, no commented-out blocks, no leftover TODOs.
- Comments only for non-obvious *why*, never *what*.
- Match existing conventions (file layout, naming, `app/globals.css` tokens).
- Only build what's asked for this step — no extra scope.
